# 3x-ui 面板

通过以下命令运行 3x-ui 官方安装脚本：

```bash
bash vps.sh 3x-ui install
```

本仓库不修改安装过程，也不写入任何面板配置。安装时请留意脚本输出的登录地址、账号和密码。

安装后运行 `x-ui` 可打开管理菜单。

## 安全建议

- 修改默认账号、密码和访问路径
- 为面板启用 HTTPS
- 在云厂商安全组中限制面板端口的访问来源

## 配合端口跳跃

在 3x-ui 中创建 Hysteria2 入站后，用入站端口配置跳跃规则：

```bash
HY2_PORT=入站端口 bash vps.sh hy2 install
```

然后在客户端填写跳跃端口范围，详见[端口跳跃文档](hy2-port-hopping.md)。
